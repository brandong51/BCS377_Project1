Finished Projects

Project 1: D&D Game

This was a collaborative group project with my fellow classmates in my Software Engineering class. My classmates Faraz, Saad, Jared, and I worked together on a D&D inspired game for the project. We used Java, JavaFX, CSS, FXML, and Firebase to create the game. We also used Git and GitHub to track our progress and collaborate on the project. In the game, the user was able to choose the size of a party, choose member of the party, roll a die to determine upgrades or downgrades from the stats that are already given by each character. The user was then able to choose their path and fight bosses and complete the quest.

My Contributions:

  • Built the user login and authentication system.
  • Managed user accounts, with their emails and usernames using Firebase/Firestore.
  • Implemented game slots per user, with the option to overwrite an existing save from the user.
  • Tested the game mechanics and fixed bugs, well everyone from the group all did this as well.

Technologies Used:

  • Java
  • JavaFX
  • CSS
  • FXML
  • Firebase/Firestore
  • Git/GitHub
  • IntelliJ IDEA

Project 2: MovieArchive

For another class project, I created a movie archive website where you can write reviews for movies that you have watched and rate them. User can also add movies to your watchlist and have an organized list of the movies that you have already watched.

Project Features:

  • Movie search functionality using the OMDB API.
  • User authentication and account management.
  • Ability to write reviews and rate movies.
  • Watchlist feature to keep track of movies to watch.
  • A relational database connecting users, movies, watchlists, and reviews.
  • User-specific lists and reviews, input validations, and prepared SQL statements.

Technologies Used:

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL
  • WAMP

Project 3: Video Game Sales Analysis

This project was a menu-driven Perl application that analyzed a dataset of video game sales. Users can view the top-selling games by year, platform, genre, and publisher through organized terminal reports.

Project Features:

  • Loaded and processed a dataset of video game sales from a CSV file.
  • Filtered and sorted records to compare sales performance.
  • Identified the highest-selling games based on various criteria.
  • Instead of a bland terminal interface, provided a more user-friendly experience with different colors from Term::ANSIColor.

Technologies Used:

  • Perl
  • CSV
  • Text::CSV
  • Term::Menus
  • Term::ANSIColor

Senior Project: CampusFix

For my senior project class, the group that I am a part of are creating a web application called CampusFix. User will be able to submit maintenance requests, view the status of their requests, reports with locations, categories, and descriptions of the issues around campus. User will be also able to add photos of the issues.
